財務諸表論 PWA 完全版（1,260問・暗号化済み）

このフォルダは、公認会計士試験 短答対策用「財務諸表論 肢別チェック」の完成版PWAです。
監査論・企業法PWAと同じ基本構成で、問題データは暗号化済みです。

【収録内容】
・全1,260問
・章別／A・B・Cランク別出題
・10問／20問／30問／50問／該当問題すべて
・シャッフル出題
・前回の続き
・前回不正解の復習
・苦手問題リスト
・ブックマーク
・章別進捗
・回答履歴の端末保存
・オフライン利用対応（Service Worker）

【セキュリティ】
・問題本文・解説は平文の questions.json では配置していません。
・vault.js に AES-256-GCM で暗号化した問題データを格納しています。
・鍵導出は PBKDF2-HMAC-SHA256（210,000回）です。
・起動時に設定済みパスワードを入力した場合のみ、ブラウザ上で復号します。
・パスワードそのものはファイル内に保存していません。

【GitHub Pagesへの配置】
このフォルダ内のファイル・フォルダをそのままリポジトリの公開対象へ配置してください。
HTTPS環境（GitHub Pages）での利用を前提としています。

【注意】
GitHub PagesのURL自体は公開URLです。robots.txt/noindex相当の設定や問題データ暗号化により検索・閲覧リスクを下げていますが、URLそのものを完全非公開にする仕組みではありません。
